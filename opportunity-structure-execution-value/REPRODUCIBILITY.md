# 复现与数据说明

## 数据来源

本包全部观测、机会世界和现金路径均由条件模型产生，不含实盘或购买行情数据。论文参考文献的公开链接保留在正文与证明中，第三方论文全文未随包转载。

## 环境

Python 3.12.14；NumPy 2.3.5、SciPy 1.18.1、Matplotlib 3.11.2、ReportLab 4.4.9。版本对应本次核验环境；核验结果单独保存。核心模式仅使用Python标准库。

原实验曾从 `_local_dependencies` 或 `_plot_dependencies` 加载库。这两个本地安装目录未打包；脚本保留原字节，公开复现从正常安装环境取得依赖即可。

## 运行

```sh
python reproduce.py --core
python -m pip install -r requirements.txt
python reproduce.py
```

入口先验证归档文件指纹，在临时副本按顺序运行并将生成JSON与归档作解析后的精确比较。不同环境可能产生浮点差异，此时入口报告不一致，不静默改写归档。SVG/PDF图形可能含时间等元数据，因此图形不做字节一致承诺；入口检查图形输出存在，保存图另以指纹核对。

每项实验运行输出和比较结果写入本地 `reproduction_output/`，该目录在 `.gitignore` 中排除。重跑原单项脚本可能改写归档或图形，优先使用统一入口。完整模式包含蒙特卡洛与线性优化，耗时高于核心模式。
