# 第四轮实质修订与验证

2026-10-11。修改对象为第一篇《机会结构如何改变执行价值》的当前重大修订主稿及证明；未修改第二篇规模测试稿。第三轮主稿和证明已分别保存于archive。当前PDF仍是第三轮历史版本；本轮审阅以更新后的Markdown及新增证明为准。

## 已完成的研究修改

1. **推广核心门槛。** 从固定a=.5、m=.25、τ=.2扩展到非空合法集合上的全参数准确判别。以最高可实现底线w_*表述停止边界，再给一个可检查的闭式达到区域：四次方程、合法概率高度、区间预算与完整共同上界。用隐函数导数证明原结果处于参数开放邻域，a、m、B、τ可独立变化。全参数判别不等于全域闭式求解；上限饱和等其他区域尚未求完。

2. **补上未知基准与候选选择。** 不再要求均匀率、机会两矩及平均费用准确已知。完整随机等待日志同时估计多个事先固定行动的净现金率，已知等待均值精确进入分母，成功后占用由同一成功读数估计。联合区间包含均匀，控制事后选择错误；非正下界返回不执行。τ、κ及周期形式仍须已知，不能称所有周期信息未知。

3. **同一模型的事前购买。** 在非负报价模型中，以环境先验和固定菜单给购买净增益条件，比较对象为事前最佳未购买固定菜单，全部记录费、训练占用、错误行动及尾部闲置进入共同截止日。新例子的两世界具有相同a、m及同一单窗口上限，却选择不同的最佳行动，因而信息价值不再只是“改善均匀”。购买界是充分条件，并非最优学习或最优价格。

4. **近邻研究比较更具体。** 核查比率优化Proposition2.1及矩误差部分、有限信息筛选附录Theorem5、随机集合可实现性§4 Theorem3。明确这些理论已经提供比率换算、矩不确定、准确最坏机制和随机集合正则性的框架。核心候选贡献集中在本文机会预算与报价制度的准确门槛；联合估计与学习流程采用标准工具，不拔高为新一般算法。尚未完成全体后续文献的优先权排除。

5. **收束与可视化。** 正文围绕四个定理组织，固定参数结果改为推论，专用探针和直接收费购买例子在正文简述、完整内容保留在补充材料。新增一般参数与同矩行动比较图；修正重复S5/S6为S8/S9，更新当前证明导航。

## 距离顶会目标的实际缺口

本轮加强的是理论适用范围与决策逻辑，尚不能据此宣称达到顶会水平。仍有四项实质研究缺口：

1. 核心门槛需要独立同行逐行审查和更全面近邻比较，确认其新颖性与重要性。
2. 闭式区域之外的概率上限饱和形状及全域解尚未完成；当前已清楚标明合法区域。
3. 净购买仍是已知先验、事先有限菜单、付费反馈权限；未解决免费学习、时间依赖行动日程和全体自适应策略的最优比较，也无匹配信息下界。
4. 没有真实时间、现金单位和稳定期校准。H=10^8是假设很强的合成例，不可直接解释为市场或机构部署证据。

没有具体目标会议时，尚未按某一会议的英文页数、匿名格式或模板制作提交包。本轮完成的是面向高水平审稿的实质研究修订，英文投稿版本、会场匹配与外部审查仍需另外完成。
